# 川农知识库 · 学生笔记功能设计（v1）

> 状态：已确认（2026-08-30 grilling 会话产出）
> 关联：[教学框架设计](川农知识库教学框架设计.md)（笔记是学生端唯一可写数据面）
> 模仿先例：user-favorites（000047，per-(user,tenant) 隔离）+ env-vars（000089，/me 前缀路由）

## 1. 背景与定位

学生在学习课程资料时需要记录个人笔记，Markdown 书写。**纯个人私有**：教师与其他学生均不可见（含计数），延续 ADR-012 隐私立场。这是学生端唯一可写的数据面。

## 2. 已确认决策

| # | 决策 | 内容 |
|---|---|---|
| N-1 | 归属可见性 | 纯个人私有；后端按 (tenant_id, user_id) 隔离；**不提供任何按空间列全体笔记的端点**——教师不可见在结构上成立，而非策略上约束 |
| N-2 | 入口 | 侧栏新增「我的笔记」→ `/platform/notes` 独立页：左侧笔记列表（按更新时间倒序）+ 右侧编辑/预览 |
| N-3 | 编辑器 | Markdown 源码编辑 + 预览切换；复用 manual-knowledge-editor 的工具栏与安全渲染管线（safeMarkdownToHTML → marked → sanitizeHTML） |
| N-4 | 保存 | 手动保存（按钮 + Ctrl+S）；未保存切换/离开弹确认 |
| N-5 | 贴图 | v1 支持：粘贴/工具栏上传图片，个人图片独立端点存取 |
| N-6 | 标题 | 无独立标题字段；列表项取笔记首个 `#` 标题（无则首行截断；空笔记显示"无标题"） |
| N-7 | 限额 | 每人 200 篇；单篇内容 ≤ 1MB；每张图片 ≤ 2MB；每人图片 ≤ 200 张（全部为常量校验） |
| N-8 | 教师可见性 | 完全不可见，使用统计也不含笔记维度 |

## 3. 数据模型（迁移 000092）

```sql
CREATE TABLE IF NOT EXISTS tenant_notes (
    id         VARCHAR(36) PRIMARY KEY,
    tenant_id  BIGINT      NOT NULL,
    user_id    VARCHAR(512) NOT NULL,   -- 与 sessions.user_id 同规格
    content    TEXT        NOT NULL DEFAULT '',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_tenant_notes_user
    ON tenant_notes (tenant_id, user_id, updated_at DESC);

CREATE TABLE IF NOT EXISTS tenant_note_images (
    id         VARCHAR(36) PRIMARY KEY,
    tenant_id  BIGINT      NOT NULL,
    user_id    VARCHAR(512) NOT NULL,
    mime       VARCHAR(100) NOT NULL,
    bytes      BYTEA       NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_tenant_note_images_user
    ON tenant_note_images (tenant_id, user_id);
```

图片访问采用 capability URL（36 位不可猜测 UUID 即访问凭证），读取端点要求登录但不校验归属——v1 折衷，文档明示。

## 4. API（全部 `/me/notes`，登录成员即可；user 从 auth ctx 取，前端不传）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /me/notes | 列表：id / preview（服务端取首行截 50 字）/ updated_at（不含 content） |
| POST | /me/notes | 新建 {content}，校验篇数与字节数限额 |
| GET | /me/notes/:id | 读取单篇（owner 校验） |
| PUT | /me/notes/:id | 保存 {content}（owner 校验 + 字节数校验） |
| DELETE | /me/notes/:id | 删除（owner 校验） |
| POST | /me/notes/images | 上传图片（multipart，≤2MB，数量校验）→ {url} |
| GET | /me/notes/images/:id | 图片字节（capability URL，登录即可） |

## 5. 前端

- menu.ts 增「我的笔记」项（无需 capability 开关）+ 路由 `/platform/notes` + 四语言文案
- `views/notes/MyNotes.vue`：列表 + 编辑器。编辑器工具栏与预览从 manual-knowledge-editor 抽取复用（textarea + wrapSelection 工具栏 + safeMarkdownToHTML 预览）
- 图片：粘贴/按钮上传 → 插入 `![](url)`；预览时对笔记内图片 URL 做 authed hydration（仿 hydrateProtectedFileImages）
- 未保存守卫：路由离开 + beforeunload

## 6. v1 明确不做

文件夹/标签/全文搜索/笔记分享/提交作业（v2 教学闭环候选）/公式渲染（v2 可升级 KaTeX 管线）/复杂配额

## 7. 验收标准（要点）

- 学生 A 创建/编辑/删除自己的笔记；学生 B 与教师均无法通过任何端点访问 A 的笔记（含枚举：不存在列全体端点）
- 超限（第 201 篇、>1MB 内容、>2MB 图片、第 201 张图）均被 400 拒绝并提示
- 刷新不丢稿：未保存离开有确认；保存后列表顺序按更新时间倒序
- 贴图：粘贴截图 → 上传 → 预览可见；刷新后仍可见

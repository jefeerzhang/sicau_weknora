# 超级管理员上手手册（小白版）

面向第一次部署川农教学版 WeKnora 的老师或管理员。  
**你不需要会写环境变量**；按本文做即可。

> **部署默认（v0.8.0）：** Docker 沙箱关、长期记忆关、复杂密码关。课堂一般不需要改这些；若有人要求「打开沙箱」，先读 `docs/sandbox-docker-backend.md` 再决定是否 opt-in。

---

## 一、从零部署后，怎么第一次登录？

系统已预设好首个超级管理员账号（空数据库首次启动时自动创建）：

| 项目 | 预设值 |
|------|--------|
| 登录方式 | **邮箱**（不是用户名） |
| 邮箱 | `admin@admin.com` |
| 初始密码 | `admin123` |

步骤：

1. 在浏览器打开本站登录页。
2. 输入邮箱 `admin@admin.com`，密码 `admin123`。
3. 系统会要求你**立刻改成自己的新密码**（这是安全要求，不能跳过）。
4. 改完后重新登录，即可进入系统。

> 改密要求：新密码 8～32 位，且同时包含字母和数字。

---

## 二、超级管理员要做什么？

你的职责很简单，只有几件平台级的事：

1. **改好自己的密码**（上面第一步）。
2. **任命教师**：在「系统设置」里找到教师管理，输入教师已有账号的邮箱，完成任命。
3. （可选）重置某位用户密码、查看平台审计日志。

你**不必**代替每位教师去建课程空间、配模型；那些由教师自己完成。

---

## 三、教师和学生怎么来？

| 角色 | 怎么产生 |
|------|----------|
| 超级管理员 | 首次部署自动创建（本手册第一节） |
| 教师 | 由你在系统设置里**任命**（可任命多名） |
| 学生 | 由教师发**邀请链接**注册/加入；默认只能使用，不能建空间 |

公开自行注册已关闭。陌生人不能自己注册成「业主」。

---

## 四、教师被任命之后会做什么？（你心里有数即可）

1. 教师登录后可以**创建自己的工作空间**（一门课一个空间也可以）。
2. 在空间里上传资料、配置模型、邀请学生。
3. 教师之间互相看不到对方的空间内容。

若教师还没配模型，学生提问会提示「工作空间尚未配置模型」，这是正常现象，让教师去设置里补模型即可。

---

## 五、运维同学才需要看的（小白可跳过）

若你请了会 Docker 的同事帮忙部署，他们只需保证启动时带有：

```bash
WEKNORA_BOOTSTRAP_SUPERADMIN_EMAIL=admin@admin.com
WEKNORA_BOOTSTRAP_SUPERADMIN_PASSWORD=admin123
```

本仓库的 `docker-compose.yml` 与 `.env.example` **已按上面预设写好**。  
只有在「空库 + 还没有任何超级管理员」时才会创建；库里已有管理员时不会重复创建、也不会改掉现有密码。

如需换成别的初始邮箱/密码，改 `.env` 里这两行后，用**全新空库**再启动即可。

## 六、常见问题

**Q：登录框要填用户名还是邮箱？**  
A：填**邮箱**。

**Q：我忘了改过后的密码怎么办？**  
A：若还有别的超级管理员，可在系统设置里帮你重置。若你是唯一管理员且密码丢失，需要懂数据库的同事协助，或按运维文档从备份恢复。

**Q：能不能有两个超级管理员？**  
A：教学部署约定为**唯一**超级管理员。需要多人管课，请任命为**教师**，不要再造第二个超级管理员。

**Q：我把初始密码告诉同事安全吗？**  
A：仅用于第一次登录。登录后立刻改密；不要把初始密码长期写在群公告里。

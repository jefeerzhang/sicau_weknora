# 川农知识库 · 公告板设计（v1）

> 状态：已确认（2026-08-30，用户需求定义明确后的收敛版）
> 本质：教师发公告（作业下发）+ 学生留言的**单向公告板**。收作业走外部链接（如坚果云），不经本系统。
> 与"讨论区"的关系：本功能即讨论区的收敛形态（发帖权收敛到教师）。

## 1. 已确认决策

| # | 决策 |
|---|---|
| A-1 | 发布权限：contributor+（教师/助教）；学生（viewer）只读 + 留言 |
| A-2 | 留言：所有登录成员可发；纯文本保留换行（无 Markdown/贴图）；平铺无嵌套；作者删自己、admin 删任何 |
| A-3 | 公告附件：单文件 ≤ 50MB、每公告 ≤ 5 个；白名单 pdf/doc/docx/ppt/pptx/xls/xlsx/zip/rar/7z/txt/md；走 **FileService** 抽象（非 BYTEA） |
| A-4 | 公告不可编辑——发错删除重发；删除 = 作者或 admin（连带删附件文件与留言） |
| A-5 | v1 不做：通知/未读标记、置顶、分类、搜索、分页（一页倒序全出）、留言统计、公告编辑 |

## 2. 数据模型（迁移 000093，归 ticket 11）

```sql
CREATE TABLE IF NOT EXISTS announcements (
    id         VARCHAR(36) PRIMARY KEY,
    tenant_id  BIGINT       NOT NULL,
    user_id    VARCHAR(512) NOT NULL,           -- 作者
    title      VARCHAR(200) NOT NULL,
    content    TEXT         NOT NULL DEFAULT '',
    attachments JSONB       NOT NULL DEFAULT '[]', -- [{name, path, size}]
    created_at TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_announcements_tenant
    ON announcements (tenant_id, created_at DESC);

CREATE TABLE IF NOT EXISTS announcement_comments (
    id             VARCHAR(36)  PRIMARY KEY,
    tenant_id      BIGINT       NOT NULL,
    announcement_id VARCHAR(36) NOT NULL,
    user_id        VARCHAR(512) NOT NULL,
    content        TEXT         NOT NULL,
    created_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_announcement_comments
    ON announcement_comments (announcement_id, created_at);
```

附件元数据存公告行内 jsonb（`[{name, path, size}]`，path 为 `provider://...` FileService 引用）。**附件随公告 multipart 一次性提交**——无编辑即无孤儿文件；删公告按 jsonb 逐个 DeleteFile。留言删公告时级联删除。

## 3. API（`/announcements`，登录成员可读；写操作角色门禁如下）

| 方法 | 路径 | 门禁 | 说明 |
|---|---|---|---|
| GET | / | viewer+ | 列表：id/title/作者名/created_at/附件数（不含正文与留言） |
| POST | / | contributor+ | multipart：title + content + files[]（≤5 个、单个 ≤50MB、白名单校验） |
| GET | /:id | viewer+ | 详情：全文 + 附件元数据 |
| DELETE | /:id | 作者或 admin | 连带 DeleteFile 附件、级联删留言 |
| GET | /:id/comments | viewer+ | 平铺留言，时间正序 |
| POST | /:id/comments | viewer+ | {content}（纯文本） |
| DELETE | /:id/comments/:cid | 留言作者或 admin | |

附件下载：`GET /announcements/:id/attachments/:index` → FileService GetFile 流式返回（登录即可，公告本就全员可见）。

作者 username 批量 hydrate 照抄 `handler/tenant_member.go` 的 GetUsersByIDs 模式。

## 4. 前端

- menu.ts 顶层加「公告板」（icon announcement.svg 新增）+ 路由 `/platform/announcements` + 四语言
- 页面 `views/announcements/Announcements.vue`：单列公告流（沿列表页惯例，非两栏）——顶部发布表单（contributor+ 可见：标题 + 内容 textarea + 文件多选，显示已选文件）+ 公告卡片（标题/作者/时间/正文 markdown 渲染复用 security.ts 管线/附件下载/留言区展开）
- 部署注意：frontend nginx `MAX_FILE_SIZE_MB` 需 ≥ 60（50MB 文件 + multipart 开销）

## 5. v1 明确不做

通知/未读、置顶、分类、搜索、分页、公告编辑、留言 Markdown 与贴图、留言统计（ADR-012 延伸）、外部链接预览。

## 6. 验收要点

- 教师/助教发公告带 3 个附件 → 全员可见可下载；学生发公告 → 403
- 学生留言 → 全员可见平铺；作者删自己留言 ✓；admin 删任何留言 ✓；学生删他人 → 404
- 删公告 → 附件文件物理删除 + 留言级联消失
- 51MB 文件 / 第 6 个附件 / 白名单外类型 → 400

# 上游同步操作记忆（川农 WeKnora）

> 从 v0.8.0 换基 + Ticket 0/A–G/QA 实战提炼。下次跟上游时先读本页。

## 一句话

**钉发布 tag 换基 → `sync/*` 分支重放川农不变量 → 空库 + 备份库双冒烟 → 你确认后再合 main。**

## 未来上游有改动时：怎么同步

### 0. 决策门

1. 以 **上游 release tag**（如 `v0.9.0`）为单位评估，**不默认追 `upstream/main`**。
2. 先写/更新规格：不变量表 + 垂直域 tickets + QA 门禁；**main 保持可部署**。
3. 大换基只在 `sync/upstream-vX.Y.Z`；紧急热修可进 main，大功能尽量延后避免双搬。

### 1. 建基座

```text
git fetch upstream --tags
git worktree / branch: sync/upstream-vX.Y.Z  ← 基于上游 tag
保留川农 diff 清单（或 cherry-pick / 按域重放）
```

### 2. 按垂直域重放（不要整坨 merge 川农）

顺序习惯：`成员/邀请 → SuperAdmin/教师 → 学生封闭 → 笔记公告 → 品牌 → 对话 UI → 部署默认 → QA`

每域：对照 SDK/表结构真源 → 实现 → 定向测试 → 中文 conventional commit → 推 sync。

### 3. QA 必做两路（最稳妥）

| 路线 | 做什么 | 禁止 |
|---|---|---|
| **Route 1 空库** | 新 compose project + 新 volume；验证引导与默认配置 | 挂载生产 volume |
| **Route 2 备份升级** | `docker volume` **克隆** 现网库 → 独立 project 起 sync 镜像跑迁移 + 冒烟 | 改密码/写数据打到**源卷**；对源卷 `down -v` |

合并前：修复必须已 **commit + push** 到 sync。

### 4. 部署与解析坑（本轮踩过）

- **`WITH_ANYDOC`**：生产/验收镜像默认 **`1`**。QA 为加速设 `0` 会导致引擎登记但 `Available=false`，UI 提示「暂无解析引擎」。anydoc 来自 `third_party/anydoc-go` + crates.io pin，不是 docreader 旁路容器。
- **升级 anydoc crate**：改 `Cargo.toml`/`version.go` → 刷新 `Cargo.lock` → 适配 `model.rs` 穷尽 match（如 Math/Checkbox）→ `NeedsOcr` 与 `PDFNeedsOCR` 文案 → 再 `WITH_ANYDOC=1` 重建。
- **`invite_only` + 空库**：必须有 SuperAdmin bootstrap（或等价引导），否则无法登录。
- **`default_agent_id`**：GORM `*string` nil ≠ SQL DEFAULT；创建路径要显式空串。
- **邀请学生**：新账号走 **`POST …/invite-links` + `register-by-invite`**，不是「邮箱邀请已注册用户」。
- **公告**：multipart，不是 JSON body。
- **Host 探针**：本机代理下 curl/浏览器需绕过代理（`127.0.0.1` / `--noproxy`）。
- **compose `container_name`**：硬编码 `WeKnora-*`，同机同时只能起一套；用不同 `COMPOSE_PROJECT_NAME` 也要先 down 再换 volume。

### 5. 合并

- 仅在你明确确认后：`sync → main`（PR 或 merge），**不 force-push main**。
- 合并前再备份一次生产 DB；合并后 Ctrl+F5 / 前端重建。

## 速查命令

```powershell
# 空库 QA
$env:COMPOSE_PROJECT_NAME='weknora-sync-qa'
$env:WITH_ANYDOC='1'
docker compose up -d

# 备份升级：克隆卷（源卷只读）
docker volume create weknora-sync-upgrade_postgres-data
docker run --rm -v weknora_postgres-data:/from -v weknora-sync-upgrade_postgres-data:/to alpine \
  sh -c "cp -a /from/. /to/"

# anydoc 开
$env:WITH_ANYDOC='1'; docker compose build app; docker compose up -d app
```

## v0.8.0 部署说明（Local 删除 / Docker opt-in）

- **Local 沙箱后端已删除**（上游 BREAKING）：文档与 UI 不得再引导「本机进程沙箱」。详见 [sandbox-protocol.md](./sandbox-protocol.md)、[QA.md](./QA.md) §45。
- **Docker 沙箱默认关闭**：`WEKNORA_SANDBOX_DOCKER_ENABLED=false`（`.env.example` / `docker-compose.yml`）。需要时再挂 `docker.sock` 并改为 `true`，或由系统管理员在「设置 → 系统设置 → 网络安全」打开。详见 [sandbox-docker-backend.md](./sandbox-docker-backend.md)。
- **长期记忆 / 复杂密码**：教学部署不作为默认开启（复杂密码 compose 默认 `false`；记忆产品默认关）。
- 本文其余章节约束的是**学生端发布集成与沙箱密钥 RBAC**（与沙箱后端是否启用无关）：即使教师开启 Docker/E2B，学生（viewer）仍不可见「沙箱密钥」与发布集成管理入口。

## Problem Statement

课程空间里，学生（空间角色 `viewer`）在「设置」侧栏仍能看到「发布集成」下的 IM 集成、网页嵌入、Chrome 插件、Claw Skill，以及账户分组里的「沙箱密钥」。这些能力面向外部渠道发布与个人沙箱凭据，不在川农 v1「学生纯问答」范围内；仅藏入口不够——学生仍可能深链或直接调 API。教师 / 助教（`contributor+`）仍需保留这些能力，不能整部署关掉。

## Solution

对学生（`viewer`）前后端同时封闭：设置侧栏与相关入口不再露出上述五项；对应管理面与个人沙箱密钥 API 对 `viewer` 返回拒绝。教师与更高角色行为不变。公开嵌入会话、IM 回调等无登录管理面的外部通道路由不在本票改动范围内。

## User Stories

1. As a 学生（viewer）, I want 设置侧栏不再出现「发布集成」分组（当其子项对学生均不可见时）, so that 我不会被外部发布能力干扰学习问答
2. As a 学生（viewer）, I want 看不到「IM 集成」入口, so that 我不会尝试配置飞书/企微等机器人渠道
3. As a 学生（viewer）, I want 看不到「网页嵌入」入口, so that 我不会尝试创建或管理嵌入通道
4. As a 学生（viewer）, I want 看不到「Chrome 插件」入口, so that 我不会被引导安装与课程无关的浏览器扩展
5. As a 学生（viewer）, I want 看不到「Claw Skill」入口, so that 我不会被引导到外部 Skill 市场
6. As a 学生（viewer）, I want 看不到「沙箱密钥」入口, so that 我不会被要求填写个人技能 / 沙箱环境变量
7. As a 学生（viewer）, I want 深链打开 `/platform/settings?section=integration-im`（及 embed / chrome / claw / envvars）时被回退到我有权访问的设置页, so that 不会看到空白或半残页面
8. As a 学生（viewer）, I want 直接调用 IM 通道列表 / 详情相关管理 API 时被拒绝, so that 仅藏 UI 无法绕过
9. As a 学生（viewer）, I want 直接调用嵌入通道列表 / 详情相关管理 API 时被拒绝, so that 仅藏 UI 无法绕过
10. As a 学生（viewer）, I want 直接调用 `/me/env-vars` 的读与写时被拒绝, so that 无法读写个人沙箱密钥
11. As a 教师或助教（contributor+）, I want 设置里仍能看到并使用 IM 集成, so that 我仍可按需配置课程对外 IM 渠道
12. As a 教师或助教（contributor+）, I want 设置里仍能看到并使用网页嵌入, so that 我仍可管理嵌入通道
13. As a 教师或助教（contributor+）, I want 设置里仍能看到 Chrome 插件与 Claw Skill 落地页, so that 教师侧扩展能力不受影响
14. As a 教师或助教（contributor+）, I want 设置里仍能看到并使用「沙箱密钥」, so that 我仍可为个人技能填写密钥
15. As a 空间 Owner / Admin, I want 既有的 IM / 嵌入通道变更、轮转 token、开关等写操作权限不被本票收紧到超出原设计, so that 管理动作仍按既有 Admin+/Owner 矩阵工作
16. As a 学生（viewer）, I want Agent 编辑器（若我根本打不开则自然满足）中的 IM / 网页嵌入快捷入口对我不可用, so that 不会从编辑器绕进集成设置
17. As a 课程产品负责人, I want 「API 集成」入口策略保持现状（已是 Owner 门槛）, so that 本票不扩大或缩小 API 集成的可见范围
18. As a 回归维护者, I want 路由注册有 tripwire 测试钉住「viewer 不可读 IM/embed 管理列表与 /me/env-vars」, so that 上游合并不会静默把学生门禁改回 Viewer+
19. As a 回归维护者, I want 前端 `SETTINGS_SECTION_MIN_ROLE` / `INTEGRATION_TAB_MIN_ROLE` 单测钉住学生对上述入口不可见, so that UI 策略与后端一致且可防回退
20. As a 学生（viewer）, I want 公开嵌入聊天页与 IM 平台回调（若教师已配置）不因本票而对我的问答主路径产生破坏, so that 封闭的是「管理入口」而非已发布通道的运行时（运行时本就不走学生设置）

## Implementation Decisions

1. **唯一测试 / 实现 Seam：空间 RBAC 角色门禁（Contributor+），前后端成对**  
   与 ADR-009-6（会话附件）、成员名单 Admin+ 同一模式：前端抬高最低可见角色，后端把仍对 `viewer` 开放的**管理面读接口**改为 `g.Contributor()`（或与写操作对齐的既有更高门槛，但不得低于 Contributor）。禁止只改前端。

2. **角色语义**  
   - 学生 = `viewer`（ADR-003 / ADR-004）  
   - 封闭线 = `contributor` 起可见/可调管理面  
   - 不把本票做成「整部署 capability `supported:false`」或「对师生永久 never-enabled」——那会误伤教师。

3. **前端设置导航**  
   - 在集成 tab 角色表中为 `im` / `embed` / `chrome` / `claw` 设最低角色 `contributor`（`api` 保持既有 `owner`，本票不改）。  
   - `SETTINGS_SECTION_MIN_ROLE.envvars` 从 `viewer` 改为 `contributor`。  
   - 「发布集成」分组在学生侧因子项过滤为空而自然不渲染（沿用现有 `navGroups` 空组过滤）；不要用「整组对师生删除 preview 列表」的方式实现。  
   - 深链 / 角色不足时走现有 Settings 回退逻辑，不新增平行路由系统。

4. **前端其它入口**  
   - Agent 编辑器内跳转 IM / 网页嵌入的快捷控件：对学生不可见或不可点（与 `hasRole('contributor')` 或等价门禁一致）。  
   - Chrome / Claw 仅为落地页 + 外链，无学生可写的专用管理 API；以前端口径 + 深链回退即可。

5. **后端 IM 管理面**  
   - 将仍为 `g.Viewer()` 的 IM 通道**列表**类路由（按 agent 列表、全量列表等管理读）提升为至少 `g.Contributor()`。  
   - 写操作若已是 Admin+，保持不变。  
   - IM 平台 callback（签名校验、无空间会员角色）不改。

6. **后端嵌入通道管理面**  
   - 将仍为 `g.Viewer()` 的 embed-channels **列表**类管理路由提升为至少 `g.Contributor()`。  
   - 写 / 轮转 / 预览 session 等保持既有 Admin+ 或更高门槛；**不要**为了「省事」改成全站 Owner-only 从而关掉教师。  
   - 公开 `/embed/...` 会话运行时路由不改。

7. **后端沙箱密钥**  
   - `/me/env-vars` 及其 skill/sandbox 的 PUT/DELETE：在注册处增加 `g.Contributor()`（或等价「非 viewer」守卫），使学生读写下均被拒。  
   - 不改 Admin+ 的沙箱配置 / 技能目录路由；教师空间级密钥入口保持原样。

8. **明确否定的实现路径（避免与未提交 WIP 混淆）**  
   - 不要把 `INTEGRATION_TAB_CAPABILITY` 指到永不支持的占位键来「对所有人隐藏」。  
   - 不要清空全体 `INTEGRATION_PREVIEW_ITEMS`。  
   - 不要把 embed 管理面整体升到 Owner-only 当作本票的学生封闭方案。  
   - 若工作区已有上述方向的未提交改动，实现本票时应按本文决策纠正。

9. **文档**  
   - 在教学框架 ADR-009 增加第 7 条，指向本 spec；本文件为实现与验收权威说明。

10. **无 schema / 无迁移**  
    纯门禁与导航策略；不新增表、不改 deployment capabilities 协议键集合。

## Testing Decisions

1. **好测试只钉外部行为**：角色为 viewer 时入口不可见且管理 API 被拒；contributor+ 仍可访问。不测具体 Vue 组件内部状态、不测 i18n 文案字面量（除非作为可访问名称契约）。

2. **后端 prior art（优先复用形态）**  
   - `internal/router/session_artifact_route_policy_test.go`（源码注册 tripwire + `g.Contributor()`）  
   - `internal/router/tenant_member_route_policy_test.go`（sicau-v1 角色钉扎）  
   为本票增加同类 tripwire：IM 管理列表、embed 管理列表、`/me/env-vars` 注册行不得再是裸 `g.Viewer()`。

3. **前端 prior art**  
   - `frontend/src/config/settingsAccess.test.ts`（已断言 `envvars: 'viewer'`——本票改为断言 `contributor`，并补充集成 tab 最低角色断言，或在 `integrations` 配置旁新增对称单测）。

4. **手工 / 验收走查**  
   - 学生账号：设置中无发布集成四项、无沙箱密钥；直接请求上述 API 得 403（或项目统一的权限拒绝形态）。  
   - 教师账号：五项仍可用，配置 IM/嵌入/密钥的主路径无回归。

5. **不测**：Chrome Web Store / ClawHub 外链是否可达；公开 embed 小部件像素级 UI；Lite 版能力矩阵（除非本票改动误触 capability 键）。

## Out of Scope

- API 集成 tab 的可见性或 Owner 门槛调整  
- 整部署关闭沙箱 / 技能 / MCP（`settings.sandbox` capability）  
- 对学生关闭「沙箱」「技能目录」Admin 页（学生本就看不见 Admin+ 项）  
- 拆除或禁用教师已创建的 IM / 嵌入通道运行时  
- 删除 Claw / Chrome 落地页代码或上游文档  
- 注册邀请、成员名单、附件、产物下载等既有学生封闭项的再设计  
- 多语言文案删词（隐藏入口即可，不必删除 i18n key）

## Further Notes

- **确认过的 Seam（用户 2026-09-01）**：仅学生端封闭；RBAC Contributor+ 成对门禁；范围含 IM、网页嵌入、Chrome 插件、Claw Skill、沙箱密钥。  
- 术语：学生 = `viewer`；发布集成 = 设置侧栏 integrations 分组；沙箱密钥 = 设置 `envvars` / `/me/env-vars`。  
- 实现时可单 ticket 落地；若拆分，建议顺序：后端门禁 tripwire → 前端角色表与单测 → Agent 编辑器入口 → 文档 ADR-009-7 勾选。

# 空间可开关的学生个人模型（仅对话）

教师仍维护工作空间模型配置（含检索用向量化/重排）；空间负责人可按课打开「学生个人模型」，允许该课学生自建仅用于对话的模型条目（地址、凭据、模型名），并覆盖默认课程 Agent 的对话模型。未选用个人模型时回落到空间对话模型；已选用却调用失败则报错、不静默改走学校账单。出站须落在「平台预置厂商域名 ∪ 本空间教师追加域名」与部署级 SSRF 的交集；个人模型按工作空间隔离，离课销毁凭据；教师可见元数据不可见明文 Key。

否决「只覆盖 Key、不建条目」：无法自选厂商与模型名。否决任意 URL：公网课等于开出站代理。否决默认全开：现网课程行为不变。

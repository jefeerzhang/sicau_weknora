## Problem Statement

新对话空状态当前显示“Hi，我是 WeKnora，让你的知识触手可及”。前半句“Hi，我是 WeKnora”占用视觉空间，也重复表达了产品身份，使页面主标题不够简洁。用户希望删除自我介绍，只保留核心口号。

## Solution

将新对话空状态的主标题精简为“让你的知识触手可及”。其他语言同步只保留各自本地化后的口号，移除问候语、自我介绍和 WeKnora 名称。标题仍使用现有位置和视觉样式；建议问题、刷新能力、输入框、模型选择及其他新对话行为保持不变。

## User Stories

1. As a user starting a new conversation, I want to see a concise headline, so that I can focus immediately on asking a question.
2. As a Chinese-language user, I want the headline to read exactly “让你的知识触手可及”, so that the page retains the intended product message without a redundant introduction.
3. As a user of another supported language, I want the headline to contain only the localized slogan, so that the experience remains consistent across locales.
4. As a returning user, I want the suggested questions and composer to remain unchanged, so that simplifying the headline does not disrupt my normal workflow.
5. As a desktop or web user, I want the shortened headline to retain the existing placement and typography, so that the page does not shift unexpectedly.

## Implementation Decisions

- Change only the new-conversation empty-state title copy.
- The Simplified Chinese title is exactly “让你的知识触手可及”.
- English, Russian, and Korean titles retain only their existing localized slogan portion; they must not contain a greeting, first-person self-introduction, or the WeKnora product name.
- Continue using the existing localization key and rendering structure. No new API, schema, route, state, or component abstraction is required.
- Preserve the current title position, typography, responsive behavior, dark/light theme behavior, and desktop drag-region behavior.
- Do not change suggested questions, refresh controls, composer placeholder, chat mode, model selector, attachments, mentions, or send behavior.

## Testing Decisions

- Use one highest-level frontend seam: render the new-conversation empty state under each supported locale and assert the user-visible title.
- Assert that the Simplified Chinese title equals “让你的知识触手可及”.
- Assert that all supported locale titles omit the former greeting, self-introduction, and WeKnora name while retaining a non-empty localized slogan.
- Assert that the suggested-question area and composer remain present, providing a focused regression check that the change affects copy only.
- Tests should verify rendered behavior and localized output, not the internal shape of locale objects or component implementation details.
- Keep the existing locale-key audit green so all supported languages continue to expose the same localization contract.

## Out of Scope

- Redesigning the new-conversation page or changing its layout, spacing, colors, typography, or responsive breakpoints.
- Changing the suggested-question content or refresh behavior.
- Changing composer controls, chat modes, model selection, attachments, mentions, or message submission.
- Renaming WeKnora elsewhere in the product, documentation, onboarding, or metadata.
- Adding new languages or changing the locale fallback strategy.

# 03 — 学生禁用会话产物下载（含友好提示）

**What to build:** 学生（viewer）无法获取会话中由 Skill 生成的文件产物：列表接口不再返回可下载内容，下载请求返回 403；前端对学生隐藏下载入口，被拒场景显示"当前版本不支持文件下载"的友好提示而非报错。教师及 contributor 以上角色不受影响。落实 ADR-009-6（后端拒绝，不能只靠前端隐藏）。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 学生账号调用会话产物列表、消息产物列表、产物下载三个接口均返回 403
- [x] 学生前端界面看不到任何产物下载按钮/入口（预览头与列表行两处下载按钮均按角色隐藏）
- [x] 若学生前端仍触发到被拒接口（如缓存残留），展示友好提示"当前版本不支持文件下载"，不出现裸错误弹窗
- [x] 教师（owner）在课程空间内使用带产物生成的功能时，产物列表与下载行为不变
- [x] 回归确认普通问答、附件上传提问（学生自己的文件）不受影响

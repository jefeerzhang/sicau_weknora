# 03 — 学生禁用会话产物下载与会话附件上传（含友好提示）

**What to build:** 学生（viewer）无法获取会话中由 Skill 生成的文件产物：列表接口不再返回可下载内容，下载请求返回 403；前端对学生隐藏下载入口，被拒场景显示“当前版本不支持文件下载”的友好提示而非报错。学生也不能在会话中上传临时附件提问：`POST /sessions/:id/attachments` 与附件列表接口收紧为 Contributor+（产品决定：纯问答部署，见框架 ADR-003/ADR-009-6），前端对学生隐藏上传入口。教师及 contributor 以上角色不受影响。落实 ADR-009-6（后端拒绝，不能只靠前端隐藏）。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 学生账号调用会话产物列表、消息产物列表、产物下载三个接口均返回 403
- [x] 学生前端界面看不到任何产物下载按钮/入口（预览头与列表行两处下载按钮均按角色隐藏）
- [x] 若学生前端仍触发到被拒接口（如缓存残留），展示友好提示"当前版本不支持文件下载"，不出现裸错误弹窗
- [x] 教师（owner）在课程空间内使用带产物生成的功能时，产物列表与下载行为不变
- [x] 学生（viewer）调用会话附件上传与附件列表接口返回 403；单条附件的读取/预览/删除仍随会话归属鉴权；前端对学生隐藏上传按钮（Input-field）
- [x] 回归确认普通问答不受影响；教师（Contributor+）上传附件与产物下载行为不变

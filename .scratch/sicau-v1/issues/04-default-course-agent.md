# 04 — 新会话默认选中课程 Agent

**What to build:** 教师在 Agent 列表把某个 Agent 标记为"空间默认"后，任何学生打开新对话页时该 Agent 已自动选中、其预绑知识库已自动带上——学生零操作进入可提问状态。教师本人同样生效，随时可手动切换其他 Agent。机制复用租户 KV（读=所有成员，写=admin），无需建表。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 教师在 Agent 列表可对某个 Agent 执行"设为空间默认"，成功后有明确反馈；同一空间仅一个默认（设置新的自动替换旧的），可取消默认
- [ ] 空间内任意成员（含 viewer、含全新浏览器/清空 localStorage）打开新对话页，默认 Agent 已选中，其绑定的知识库已自动预选
- [ ] 成员手动切换成其他 Agent 后，以成员本地选择为准，不被默认值反复覆盖；下次清空本地数据后仍回落到默认
- [ ] 未设置默认的空间行为与现状完全一致（不改变无默认时的体验）
- [ ] 默认 Agent 被删除后，空间回落到无默认状态，不报错

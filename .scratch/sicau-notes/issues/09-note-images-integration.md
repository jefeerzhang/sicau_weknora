# 09 — 笔记贴图（粘贴/上传 + 预览取图）

**What to build:** 学生在笔记编辑器里粘贴截图或点图片按钮上传，正文插入图片引用，预览与再次打开时图片正常显示（经认证取回字节做 hydration）。

**Blocked by:** 07 — 笔记图片上传与访问；08 — 前端「我的笔记」页面

**Status:** ready-for-agent

- [ ] 编辑器支持粘贴板图片直接上传（clipboard paste 事件捕获 image）
- [ ] 工具栏图片按钮可选文件上传；上传中禁用并显示状态
- [ ] 成功后在光标处插入 `![](返回的url)`；失败提示可读
- [ ] 预览与重开笔记时，图片经认证 fetch → objectURL 显示（仿 hydrateProtectedFileImages 模式），不裸暴露未认证 src
- [ ] 超限/失败不插入残留引用；列表页摘要不受图片语法干扰（取首行可读文本）
